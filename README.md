# ubiquitous-disco
## Landing page

`index.html` is a self-contained static landing page (no build step). Open it in a browser or deploy to any static host (GitHub Pages, Netlify, Vercel).

To customise: replace the placeholder name "Setu Health Data" and the contact email `hello@setuhealthdata.com` (also set as `CONTACT_EMAIL` in the script at the bottom).
